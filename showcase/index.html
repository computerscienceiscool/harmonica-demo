Bubble Tea + Lip Gloss + Harmonica

One spring, five real-world stories.

This terminal demo uses Harmonica to make progress move naturally between stages. Select a scenario with 1–5, then move through it with ←/→ or h/l.

File transfer

Copy a backup or Grid/CAS bundle, then verify its checksum.

Test suite

Move from selecting checks through unit and integration results.

Order shipment

Follow a shipment from invoice discovery through printing.

Agent work queue

Show research, implementation, testing, and handoff as visible stages.

Media upload

Prepare, upload, and verify a photo or video.

Demo only. These recordings use simulated stage changes. They do not copy files, run tests, purchase labels, message agents, or upload media.

The VHS tape files used to generate the recordings are included in this repository. If a recording is not visible yet, run its matching .tape file after repairing local VHS capture.
