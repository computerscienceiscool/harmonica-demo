Bubble Tea + Lip Gloss + Harmonica

Five small terminal apps with natural motion.

Each recording is a separate interactive program. Harmonica gives transitions a little weight and continuity; it is not a one-size-fits-all progress-bar widget.

File transfer monitor

Starts, pauses, resumes, and finishes a backup transfer with checksum confirmation.

Test dashboard

Moves through a concise set of quality gates and marks each completed check.

Shipment tracker

Tracks a parcel across collection, delivery, and final arrival.

Agent work queue

Completes, blocks, and advances individual work items without hiding status.

Media uploader

Uploads three different media files one at a time with independent progress.

Demo only. These recordings use simulated stage changes. They do not copy files, run tests, purchase labels, message agents, or upload media.

The VHS tape files used to generate the recordings are included in this repository. If a recording is not visible yet, run its matching .tape file after repairing local VHS capture.
